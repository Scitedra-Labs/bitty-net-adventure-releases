# הרפתקת הרשת של ביטי · Bitty's Net Adventure (Beta 0.4.1)

_(לשעבר ממלכת הענן · formerly Cloud Kingdom)_

**עברית** — משחק פלטפורמה מקורי לילדים (6+) על בטיחות ברשת, מבית Scitedra Labs. 35 שלבים ב־7 עולמות, צינורות קסם, 3 דרגות קושי, מוזיקה מקורית, ניקוד ופנייה לבן/בת, 4 שפות. בלי פרסומות ובלי איסוף מידע.
המאגר הזה מכיל רק קבצי הורדה ומידע לבודקים — בלי קוד מקור.

**English** — An original kids' platformer (ages 6+) about online safety by Scitedra Labs. 35 levels in 7 worlds, warp pipes, 3 difficulty levels, original music, 4 languages. No ads, no data collection.
This repository holds downloads and tester info only — no source code.

## מה חדש ב־0.4.1-beta · What's new in 0.4.1-beta
- מסך פתיחה פשוט: התחל, משחק חדש (עם אישור), התחבר, הגדרות · Simple title: Start, New game (with confirm), Sign in, Settings
- הגדרות ב־4 קבוצות (שחקן, משחק, קול, תצוגה ושמירה), כל אפשרות במסך משלה עם "חזרה" · Settings in 4 groups (Player, Game, Sound, Display & save), each option on its own screen with Back
- תפריט קול: מוזיקת רקע, צלילים ודיבוב בנפרד · Sound menu: background music, effects and narration, each on/off
- המוזיקה נחלשת אוטומטית בזמן דיבוב · Music dips automatically while the narrator speaks
- קול המספר (אישה/גבר) וקצב דיבוב (איטי/רגיל/מהיר) עם משפט לדוגמה · Narrator voice (female/male) and speed (slow/normal/fast) with a sample line
- מטבעות בגובה ההליכה בכל 35 השלבים; מעל במות נעות — שורה אחת מעליהן · Walk-level coins in all 35 levels; one line above moving platforms
- השהייה: המשך, התחלה מחדש, מפה, הגדרות · Pause: Resume, Restart, Map, Settings
- שמירה בענן עם Google (בדפדפן), מוגנת: רק הבעלים קורא וכותב · Cloud save with Google (browser), owner-only access
- 4 שפות (עברית עם ניקוד, English, العربية, Русский) · 4 languages
