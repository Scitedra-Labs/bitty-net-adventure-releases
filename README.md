# הרפתקת הרשת של ביטי · Bitty's Net Adventure (Beta)

> עד גרסה 0.3.1 נקרא "ממלכת הענן" · Called "Cloud Kingdom" up to v0.3.1

**עברית** — משחק פלטפורמה מקורי לילדים (6+) על סכנות ובטיחות ברשת, מבית Scitedra Labs. ביטי הרובוט רץ, קופץ ויורה ניצוצות כדי לתפוס וירוסים, לפוצץ ספאם ולנצח בוסים. 35 שלבים ב־7 עולמות, צינורות קסם, 3 דרגות קושי, מוזיקה מקורית, ניקוד ופנייה לבן/בת, 4 שפות, שמירה בענן (בדפדפן). בלי פרסומות.
המאגר הזה מכיל רק קבצי הורדה ומידע לבודקים — בלי קוד מקור.

**English** — An original kids' platformer (ages 6+) about online dangers and safety by Scitedra Labs. Bitty the robot runs, jumps and shoots sparks to catch viruses, pop spam and beat bosses. 35 levels in 7 worlds, warp pipes, 3 difficulty levels, original music, 4 languages, cloud save (browser). No ads.
This repository holds downloads and tester info only — no source code.
